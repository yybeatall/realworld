# 访客签到系统

## 功能说明

本系统实现了访客签到的完整流程，包括以下功能：

### 1. 待机页面
- 显示企业Logo、欢迎语和签到按钮
- 支持背景图、企业Logo、欢迎语的后台配置

### 2. 验证页面
- 支持手机号和身份证号两种签到方式
- 验证访客信息是否与已有访客信息匹配

### 3. 人证比对页面
- 提供友好的提示信息
- 预留了硬件采集和比对的接口

### 4. 确认页
- 显示访客的详细信息
- 支持打印访客证（当天行程）
- 非当天行程或无行程时提示访客与邀约人联系

### 5. 访客证件打印页面
- 提供打印完成按钮

## 技术栈

- HTML/CSS/JavaScript 前端页面
- Express.js 后端服务
- SQLite 数据库（待完善）

## 使用方法

1. 安装依赖：`npm install`
2. 启动服务：`node app.js`
3. 访问页面：`http://localhost:3000/checkin.html`
